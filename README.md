# DEERE // CYCLEBOOK

An equity research report on Deere & Company, built in Power BI.

**See it:** [johndeere.jarabana.com](https://johndeere.jarabana.com)

**Run it live:** download the repo, keep the folder whole, and open `DEERE_CYCLEBOOK.pbip` in Power BI Desktop (Windows). Choose **Refresh** to pull the latest FRED and Nasdaq data.

**Update the web page:** with the report open in Desktop, run `node tools/web/export_web.js`, then push to `main`.

Every figure is tagged ACTUAL (reported), GUIDANCE (management's outlook) or MODEL (my assumption). The scenarios are my assumptions, not investment advice.
